# SoccerLife Bot (LLM Agent)

Это бот-агент для браузерной игры [SoccerLife.ru](https://soccerlife.ru/). Он использует Playwright для навигации по сайту и OpenAI API для принятия решений.

## Настройка

1. Создайте файл `.env` в корне проекта (если его нет) со следующим содержимым:
   ```env
   SOCCERLIFE_LOGIN="ваш_логин"
   SOCCERLIFE_PASSWORD="ваш_пароль"
   OPENROUTER_API_KEY="ваш_openrouter_api_key"
   ```

2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   playwright install chromium
   ```

## Использование

1. **Авторизация**: Сначала необходимо авторизоваться на сайте и сохранить сессию. Выполните команду:
   ```bash
   python auth.py
   ```
   В случае успеха появится сообщение `SUCCESSFUL_LOGIN`, и будет создан файл `state.json` (он содержит куки вашей сессии).

2. **Запуск агента**: Для запуска ежедневных рутинных задач выполните:
   ```bash
   python tasks.py
   ```
   Скрипт откроет браузер с использованием сохраненной сессии, соберет данные о команде и тренировках, и передаст их в OpenAI. LLM ответит, какие действия нужно предпринять.

## Архитектура

* `auth.py` — Скрипт авторизации.
* `agent.py` — Основной класс `SoccerLifeAgent`, отвечающий за взаимодействие с браузером и OpenAI.
* `tasks.py` — Скрипт запуска автоматизации рутинных задач.
* `knowledge_base/` — Папка (добавлена в .gitignore) с правилами игры в формате Markdown, которые бот может использовать для справки.

Вы можете изменить используемую модель LLM, добавив в `.env`:
```env
LLM_MODEL="ваша_модель"
```
По умолчанию используется `minimax/minimax-m3:free`.
